# Shinobi Team Hub V4 — таблицы аналитики и модерации

Изменения в `stats_api.py`:
- Поиск по уже загруженной таблице реферальных ссылок.
- Поиск по уже загруженному журналу AI-модерации.
- Экспорт видимых строк таблиц в CSV (UTF-8 BOM, разделитель `;`).
- Кнопки повторной загрузки и адаптивная бело-голубая панель инструментов.
- Сохранены существующие серверные маршруты, RBAC, Telegram Login и логика бота.

Не добавлялись новые серверные функции и не изменялась схема PostgreSQL.

Проверено: `python -m py_compile`, синтаксис всех встроенных JS через `node --check`, целостность ZIP.
Не проверено: реальное развёртывание Railway, работа с живой БД и браузерное тестирование.
