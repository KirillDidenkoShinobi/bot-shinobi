# Shinobi Team Hub V15

Добавлены owner-only API и веб-инструменты для назначения/снятия администраторов бота, удаления пользователя из базы и управления рекламной ссылкой. Все API проверяют серверную роль owner.

Ограничения: удаление пользователя из базы не отзывает его реферальные ссылки в Telegram автоматически; старая логика бота сохраняется. Остальные команды старого меню и полная интеграционная проверка не завершены. Не считать полностью финальным релизом.
