# Оформление заявок Shinobi Team

Карточки заявок в Staff и ЛС оформлены в строгом текстовом стиле без эмодзи: бренд, статус, имя с ссылкой на профиль, username, ID, группа, источник и время подачи. Кнопки «Принять» / «Отклонить» сохранены. После решения карточка обновляется с указанием администратора, места и времени решения.

Telegram Bot API не поддерживает произвольную HTML/CSS-карточку внутри сообщения, поэтому используется HTML-разметка Telegram и inline-кнопки.

Изменения касаются только оформления сообщений о заявках. Логика обработки заявок, статистика и ссылки не изменены. Проверено компиляцией Python, без подключения к Telegram.
