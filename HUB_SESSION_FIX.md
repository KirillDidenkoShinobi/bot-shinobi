# Shinobi Team Hub — исправление диагностики и срока сессии

- В Railway Logs при отказе OIDC теперь отображается `[HUB OIDC ACCESS DENIED] uid=...`. Сверьте uid с `HUB_OWNER_IDS`.
- ID Telegram-бота (Client ID) не равен Telegram ID владельца. Авторизация под другим аккаунтом не даёт прав.
- Сессия автоматически отзывается после 30 минут бездействия, максимум 12 часов с момента входа.
- При явном выходе `/logout` сервер отзывает сессию и удаляет cookie.
- Приложение Telegram не разлогинивается; сторонний сайт не может управлять сессией Telegram.
- Добавлена совместимая миграция `last_seen` в hub_sessions.
- Не отправляйте Client Secret, токены или полный URL callback с `code` третьим лицам.
