# Shinobi Team Hub V6 — Live staff schedule

- Живой редактор обязанностей и выходных в разделе «График и выходные».
- Общий источник данных с Telegram-ботом: PostgreSQL `hub_schedule_state` (при наличии DATABASE_URL).
- Однократный импорт текущего `admin_assignments.json`, если запись в БД ещё не существует.
- Сохраняются текущие часы; редактор меняет только обязанности и статус выходного.
- Изменение графика через сайт доступно владельцу и заместителю, с аудитом.
- Старые XLSX-отчёты оставлены отдельно как снимки.

ВАЖНО: при нескольких инстансах бота используйте один PostgreSQL. Изменения, сделанные в Telegram одновременно с изменениями через сайт, могут перезаписать друг друга; для строгой конкурентной записи понадобится транзакционный per-day API. Проверьте функции на тестовом Railway окружении перед production.
