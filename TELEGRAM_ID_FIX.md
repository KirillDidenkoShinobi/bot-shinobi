# Telegram OIDC: исправление Telegram ID

Причина: прежний callback использовал `int(claims["sub"])`. Telegram OIDC возвращает отдельный `sub` и числовой `id` (при scope `profile`). RBAC и `HUB_OWNER_IDS` используют Bot API Telegram ID.

Изменено: после полной проверки JWT подписи, issuer, audience и срока действия используется только проверенное поле `id`. Если `id` отсутствует, имеет неверный тип или вне диапазона Telegram Bot API user ID — вход отклоняется. Fallback на `sub` или имя пользователя запрещён.

Настройка: `HUB_OWNER_IDS=1197818066`; `TELEGRAM_CLIENT_ID`, `TELEGRAM_CLIENT_SECRET`, `HUB_PUBLIC_URL` оставьте как прежде.

Тест: откройте сайт, нажмите «Войти через Telegram», подтвердите вход, проверьте доступ владельца. Старые сессии и БД не удаляются.

Автоматическое завершение сессии: 30 минут бездействия, максимум 12 часов.
