# shinobi-bot
## Shinobi Stats
В проект добавлен защищённый API архива отчётов. Перед запуском скопируйте `.env.example` в `.env`, задайте новый `BOT_TOKEN` и одинаковый `SHINOBI_STATS_API_KEY` в боте и локальном Shinobi Stats.

## Обновление 2026-09-27 — Server Tags + Web App

- Новый участник основного чата получает вопрос о сервере.
- Ответ принимается только reply на сообщение бота в течение 20 минут.
- Тег выдаётся обычному участнику через Telegram Bot API `setChatMemberTag`.
- Боту необходимо админ-право `can_manage_tags` (Управление тегами).
- Поддерживаются одиночные/комбинированные теги из `shinobi_server_tags.txt`; более 3 серверов => `Унив серв`.
- Временная запись ожидания удаляется после выдачи или истечения 20 минут.
- Вопрос и ответ очищаются из чата; подтверждение с упоминанием удаляется через 20 минут.
- История выданных тегов сохраняется в `data.json` / PostgreSQL persistence.
- В веб-панели появилась вкладка `🎛 Управление`: пользователи, группы, история тегов, ручная выдача тега, доступ к командам.
- Для кнопки Web App задайте `SHINOBI_WEBAPP_URL=https://<ваш-домен>/dashboard`.

## Shinobi Moderation v6
- AI + ручная модерация используют единый журнал.
- ПРЕД действует 7 дней и не считается WARN.
- WARN действует 7 дней; 3 активных WARN = временный бан на 2 дня, затем WARN сбрасываются.
- Команды Staff в группах: `.пред`, `.преды`, `.снятьпред`, `.варн`, `.варны`, `.снятьварн`, `.мут`, `.размут`, `.бан`, `.разбан`, `.нарушения`, `.модлог`, `.наказание`.
- Команды модерации обходят общий запрет команд в группе, но выполняются только для участников Admin Staff.
- Цель можно указать reply, `@username` (если пользователь известен боту) или Telegram ID.
- Сроки: `30м`, `2ч`, `1д`; для `.бан` поддерживается `навсегда`.
