# Shinobi Team Hub V11 — чистые личные сообщения

- /start больше не показывает реферальное меню и старую клавиатуру.
- Администрация получает новое приветствие и ссылку на Hub, с рекомендацией попробовать VPN, если сайт недоступен.
- Неавторизованным пользователям показывается короткое сообщение об ограничении доступа.
- Фоновая рассылка напоминаний контент-плана отключена.
- Сами обработчики команд и функциональность сайта не удалены. Ранее отправленные сообщения в Telegram автоматически не исчезают.
- Для ссылки нужен HUB_PUBLIC_URL с HTTPS (или SHINOBI_WEBAPP_URL).
